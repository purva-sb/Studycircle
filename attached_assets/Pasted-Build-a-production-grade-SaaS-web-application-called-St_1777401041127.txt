Build a production-grade SaaS web application called **StudyCircle** — the ultimate social learning, focus, and exam-preparation platform for serious students preparing for competitive exams like GATE, JEE, NEET, CAT, UPSC, placements, and university exams.

---

# Core Vision

StudyCircle combines the best elements of Yeolpumta, Discord, Microsoft Teams, and Testbook into one unified platform.

Students should be able to:

* Track study time
* Join live focus rooms
* Collaborate with peers
* Participate in study communities
* Attempt mock tests
* Analyze performance
* Build streaks
* Earn XP
* Stay accountable

The goal is to help students become consistent, competitive, and connected.

---

# Tech Stack

* Frontend: React + TypeScript + Vite
* Backend: Node.js + Express
* Database: PostgreSQL
* ORM: Prisma
* Authentication: Clerk
* Real-time Communication: Socket.IO
* Voice/Video/Screen Sharing: LiveKit
* State Management: Zustand + TanStack Query
* UI Components: Tailwind CSS + ShadCN UI
* Rich Text Editor: TipTap
* Collaborative Editing: Yjs
* Calendar: FullCalendar
* Whiteboard: Excalidraw
* Animations: Framer Motion
* Deployment: Vercel + Railway/Supabase
